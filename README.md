# SVEconomy - Плагин золотой экономики
****

**SVEconomy - плагин на ванильную экономику в майнкрафn.**

**Информация:**
> Ядро: Paper\
> Версия: 1.21.11\
> Версия плагина: 1.0

**Курс валюты:**
> Кусочек золота: 1 монета\
> Золотой слиток: 9 монет\
> Золотой блок: 81 монета
****
## Как собрать плагин?

**Что бы собрать плагин после всех изменений нужно ввести команду:**
```mvn clean package```

**Плагин появится в папке target.**
